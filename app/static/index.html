FAQ

Built for a real tool website

Where are uploaded files processed?

Files are processed on the server running this app. Add your own scheduled cleanup policy in production.

Is background removal AI-powered?

If the optional rembg package/model is installed, the app uses it automatically. Otherwise it falls back to an offline GrabCut method.

Does video processing need an API?

No. Upscaling, enhancement, compression, audio extraction, and conversion use FFmpeg.
